# 12-Step Companion V4.1 — Cross-Platform PWA Test Build

This is a mobile-first Progressive Web App test build.

## Included
- 12 Steps with descriptions and guided reflection prompts
- Step-work notes saved locally on the device
- Sobriety day counter
- Daily check-ins
- Meeting tracker
- Sponsor/sponsee preparation area
- Background themes
- Emergency Help
- Install-to-home-screen behavior
- Offline cache/service worker
- Android/iPhone responsive UI

## Testing
Serve the folder over HTTPS (required for normal PWA installation). Open the site on a phone and install it to the Home Screen.

On iPhone, Safari supports **Share → Add to Home Screen → Open as Web App → Add**. The resulting icon opens the website like an app.

This build is intentionally PWA-first. A later release can wrap the same production web app for store distribution after testing and security review.
