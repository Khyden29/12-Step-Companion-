# 12-Step Companion V4.1 Beta 2

Cross-platform PWA test build. Includes interactive sobriety tracker, Sponsor/Sponsee portal prototype, Settings tab, themes, text-size controls, profile, display name, notification permission preference, language preference, planned/attended meetings, Step Work, Check-Ins, and corrected app icon path.

Sponsor/Sponsee account-to-account communication is intentionally not represented as production-secure in this prototype. A secure backend, authentication, permissions, and encrypted transport/storage are required before real recovery information is exchanged between accounts.
